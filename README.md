# JobSeekerAI

A privacy-focused iOS application for job searching and resume optimization powered by local AI.

## Features
- **Job Search**: Filter by location, wage, job type, and more.
- **Resume Management**: Create, upload, and manage resumes locally.
- **AI-Powered Suggestions**: Get personalized job recommendations based on your resume.
- **Smart Resume Tailoring**: Automatically modify resumes for specific job descriptions using local AI.
- **Suitability Check**: AI-driven insights on whether your current resume meets job requirements.
- **Local-First Privacy**: No data is ever sent to external servers.

## Tech Stack
- Swift, SwiftUI
- SwiftData (Local Persistence)
- Core ML / Natural Language Framework (Local AI)
